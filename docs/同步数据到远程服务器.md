第 1 步：本地导出（在你的 Mac 上执行）


mysqldump -h 127.0.0.1 -u root -p123456 ecommerce > ecommerce_dump.sql
如果本地没装 mysql 客户端，可以用 Docker 执行：


docker run --rm mysql:8 mysqldump -h host.docker.internal -u root -p123456 ecommerce > ecommerce_dump.sql
第 2 步：上传到阿里云服务器


scp ecommerce_dump.sql root@你的服务器IP:/tmp/
第 3 步：在服务器上导入

先建库，再导入：


mysql -h 127.0.0.1 -u root -p -e "CREATE DATABASE ecommerce CHARACTER SET utf8mb4;"
mysql -h 127.0.0.1 -u root -p ecommerce < /tmp/ecommerce_dump.sql
